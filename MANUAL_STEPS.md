# Оставшиеся ручные шаги

Автоматические локальные проверки перечислены в `AUDIT_REPORT.md`. Здесь оставлено только то, что требует внешней среды или человека.

1. Выполнить `ruff check config studio manage.py` после установки `requirements-dev.txt`.
2. Запушить проект в GitHub и дождаться зелёного GitHub Actions workflow.
3. Провести финальный ручной browser pass в Chrome/Edge на Windows: keyboard navigation, 200% zoom, Console и Network.
4. Выбрать deployment platform, домен и настроить DNS/HTTPS.
5. Подключить production PostgreSQL и проверить конкурентную запись на один слот.
6. Добавить реальные SMTP credentials, если письма должны приходить в настоящий mailbox.
7. Добавить Telegram credentials только при необходимости.
8. Заменить демонстрационные фото, контакты и юридические данные перед запуском реального бизнеса.
9. Подключить аналитику и monitoring согласно требованиям владельца.

Секреты должны храниться в переменных окружения и не добавляться в Git или ZIP.
